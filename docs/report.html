Cómo se calcula

Una fila por reseña; el ranking de productos sale de un archivo aparte del proyecto.

  1. Cada fila es una reseña; la polaridad ya viene calculada en el CSV (compound de VADER).
  2. La tasa negativa de un producto es reseñas negativas / reseñas de ese producto, no / total.
  3. Los productos de la tabla son los que aparecen en outputs/top_negative_products.csv del proyecto.
  4. No se recalculan sentimientos: se agrega la columna que produjo el pipeline de NLP.

Qué no dice este informe

Los cortes que este dataset no sostiene.

  • El ranking solo mira productos con volumen suficiente en la muestra; el resto no aparece.
  • Una tasa negativa alta con pocas reseñas es ruido, no una señal.
  • VADER falla con ironía y sarcasmo, que en reseñas es habitual.
  • No hay fechas por reseña, así que no se puede ver si el problema es actual o viejo.
